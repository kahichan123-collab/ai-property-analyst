=====================================================================
 AI Property Analyst — 香港住宅物業分析模型
=====================================================================

這是一個離線可用的物業分析工具。輸入一間樓的資料，它會用確定的
財務模型算出：可負擔性、壓力測試、租金回報、情境分析、風險、
最大買入價，最後給出一個判決（買入 / 議價 / 觀察 / 放棄）。

---------------------------------------------------------------------
 如何啟動（Windows）
---------------------------------------------------------------------
 1. 雙擊  start_here.cmd
 2. 瀏覽器會自動開啟（若沒有，自己開 http://127.0.0.1:8765/ ）
 3. 登入：帳號任意（例如 owner） · 密碼 hkhouse2026

 要停止：關閉那個黑色視窗。

 若 8765 埠被佔用，改用例如：
     start_here.cmd 8888

---------------------------------------------------------------------
 如何啟動（Mac / Linux）
---------------------------------------------------------------------
 在 Terminal 進入這個資料夾，執行：
     bash start_here.sh
 然後開 http://127.0.0.1:8765/

---------------------------------------------------------------------
 先看範例報告（不需要安裝任何東西）
---------------------------------------------------------------------
 打開  examples\demo_report.html  即可，雙擊就能看。
 那是一個完整報告的實際輸出，可以先用它了解報告長什麼樣。

---------------------------------------------------------------------
 需要什麼環境
---------------------------------------------------------------------
 * Python 3.10 或以上（唯一需求）
 * 不需要 pip install 任何第三方套件 — 全部用 Python 標準庫寫成
 * 不需要 Node、資料庫、網路

 沒有安裝 Python 的話，就只能看 examples 裡的示範報告，
 無法自己輸入新的樓盤資料。

---------------------------------------------------------------------
 離線可用嗎？
---------------------------------------------------------------------
 可以，完全離線可用。

 報告裡的「官方數據」來自香港政府公開 API（HKMA 住宅按揭統計、
 土地註冊處成交量），資料已經預先抓取並存在 .cache 資料夾，
 所以第一次開啟就有數據，不需要連網。

 若連網，它會自動更新（每 12 小時一次）。若無網路，它會沿用
 已快取的數據；連快取都沒有就略過該部分，報告其餘內容照常產生。

 想完全關閉連網功能：
     Windows :  set OFFICIAL_DATA=0   然後再啟動
     Mac/Linux: export OFFICIAL_DATA=0

---------------------------------------------------------------------
 選填：AI 敘述
---------------------------------------------------------------------
 報告最後有一節「AI 敘述」，會用 DeepSeek 把數字寫成文字解釋。

 這需要你自己的 DeepSeek API key。沒有 key 的話，報告其他部分
 完全照常產生，只是那一節會顯示「未附加：沒有設定 API key」。
 那不是錯誤，是設計如此 — AI 只負責解釋，所有數字都是程式算的。

 要啟用：設定環境變數 DEEPSEEK_API_KEY 後再啟動。

 不想用 AI 也可以：CLI 模式加 --no-llm 參數。

---------------------------------------------------------------------
 想改判決門檻 / 假設？
---------------------------------------------------------------------
 所有政策數字都集中在一個檔案：
     tools\config.py

 例如：DSR 上限、壓力測試幅度、各情境的租金與利率衝擊、
       LTV 上限、風險門檻、判決門檻 — 全部在那裡。
 改完重新啟動即可，不需要改動其他程式。

---------------------------------------------------------------------
 重要須知
---------------------------------------------------------------------
 * 這是分析工具，不是投資、稅務或按揭建議。
 * 銀行批核、物業估值與法規須另行核實。
 * 模型輸出取決於你輸入的數字與已標示的假設。
 * 系統「不會」自行捏造數字：資料不足時它會顯示
   Insufficient Data 並說明缺什麼，而不是猜一個值。

---------------------------------------------------------------------
 驗證程式正常（選用）
---------------------------------------------------------------------
 在資料夾內執行：
     python -m tests.test_underwriting
     python -m tests.test_upgrade
 兩者全過即代表引擎與報告都正常。
