這個檔案是甚麼 / What this file is

這是 AI Property Analyst v2.0 的兩份實際輸出報告（自住模式、出租模式）， 由同一個引擎在同一次建置中產生，數字沒有經過人手修改。 整個檔案是一個獨立的 HTML，雙擊即可開啟：不需要 Python、不需要安裝任何東西、不需要網路。

上方兩個分頁切換報告；切換後可直接用瀏覽器列印或「另存為 PDF」。

它做甚麼 / What the prototype does

物業 URL / 手動輸入
  → 資料抽取（嚴格，不猜數字）
  → 確定性承銷計算（按揭、DSR、首期現金、可負擔性）
  → 購置成本模型（AVD 從價印花稅、律師、代理、雜費）
  → 估值引擎（叫價 vs 公允價值）
  → 市場研究（同類成交、租金、按揭、政策）
  → 情境引擎（BEAR / BASE / BULL）
  → 利率壓力測試
  → 市場狀態分類
  → 風險引擎（等級 + Top 3：風險→機制→影響→對策）
  → 交易邊界（「在甚麼條件下」才成立）
  → 投資判決（BUY / NEGOTIATE / WATCH / PASS）
  → AI 敘述（選填，只負責解釋）
  → 14 節報告

核心原則：先確定性計算，後 AI 解釋。 AI 不得計算或修改任何財務數字 —— 按揭供款、LTV、DSR、現金需求、租金回報、 IRR、公允價值、最大買入價、風險等級、判決，全部由 tools/*.py 以純 Python 計算。 沒有 API key 時整條管線照樣完成，只是不附上 AI 敘述（本檔案即是如此）。

如何自己執行 / How to run the interactive version

需求：Python 3.10 或以上，不需要 pip install 任何套件（全部用標準庫）；不需要 Node、資料庫。

Windows：雙擊分享包內的 start_here.cmd，瀏覽器會開 http://127.0.0.1:8765/（登入：帳號任意，密碼 hkhouse2026）。 Mac / Linux：bash start_here.sh。

命令列：

python analyst.py --price 8300000 --area 741 --income 90000 \
    --ltv 60 --rate 4.125 --tenure 30 --purpose owner_occupier \
    --cash 5000000 --available-cash 5000000 --out report.html

python analyst.py --price 8300000 --area 741 --income 90000 --ltv 60 --rate 4.125 \
    --purpose rental --rent 27000 --vacancy 5 --exit-cap 3.5 --hold-years 5 \
    --out report_rental.html

驗證引擎：python -m tests.test_underwriting（28 項錨點）與 python -m tests.test_upgrade（257 項驗收檢查），本建置全部通過。

閱讀報告時該注意甚麼 / How to read it

  • 判決有條件。報告不會只說「買」或「不買」，而是列出 BUY IF / PASS IF 的具體門檻， 以及「甚麼會改變判決」。
  • 每個數字都有出處標籤。Observed（公開資料）／User Input／Estimated／Assumption／ Research Approximation／Model Output 分開顯示，第 13 節列出硬證據與軟假設的比例。
  • 資料不足時不會猜。估值會回傳 Insufficient Data 並說明缺甚麼， 而不是給一個看起來合理的數字。
  • 兩個模式的差異是真實的。同一間樓、同一筆收入，自住模式判 BUY， 出租模式判 PASS —— 因為出租要通過租金回報與壓力現金流的額外門檻。 這正是原型存在的理由：同一個價格，對不同目的是不同的決定。
